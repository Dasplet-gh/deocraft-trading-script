> **Архивный проект — скрипт больше не работает на сервере DeoCraft.**
>
> Эксплойт, который использовал скрипт, исправлен. Код и инструкции сохранены для исторической справки.

### Описание и инструкции

_Скрипт автоматической торговли с жителями на матрице Minecraft-сервера DeoCraft._

#### Примечание к матрице

- Вход на торговую матрицу без инструктажа и соблюдения правил строго запрещён.
- Для получения доступа к матрице следует обратиться к DanexusS или Dasplet.

#### Инструкция по использованию

**После запуска скрипта можно изменить параметры.** Введите номер нужной команды: показать значения всех параметров, изменить один из них или завершить настройку. После настройки можно начать торговлю.

**Все параметры описаны ниже.**

**Перед началом расположитесь под люком на главном острове Энда.** Персонаж должен находиться в лежачем положении в воде. Затем прицельтесь в середину нижней половины сундука-ловушки.

Убедитесь, что в инвентаре есть необходимые ресурсы и, при необходимости, свободное место. Нужный житель должен находиться в центре матрицы.

**Сочетания клавиш:**

- **Shift + Esc** — полностью завершить работу скрипта.
- **Shift + B** — начать или приостановить торговлю.
- **Shift + V** — остановить текущий цикл торговли и вернуться к настройке параметров.

**Приостановить торговлю можно только в паузе между покупками, после выхода из меню торговли.**

**Чтобы полностью остановить цикл торговли, сначала приостановите его сочетанием Shift + B, затем нажмите Shift + V.**

#### Параметры

1. **Номер монитора**, на котором запущен Minecraft. Мониторы нумеруются слева направо, начиная с 1. [По умолчанию: 1]
2. **Размер интерфейса** в Minecraft. Настройка не реализована. [По умолчанию: 3]
3. **Номер торгового слота** у жителя: от 1 до 14 включительно, сверху вниз. [По умолчанию: 1]
4. **Количество покупок**: целое число от 1. Для бесконечной торговли введите `-1`. [По умолчанию: -1]
5. **Пауза между покупками**: неотрицательное число, задаётся в секундах. [По умолчанию: 2]

#### Предупреждения

- Скрипт рассчитан только на мониторы с разрешением Full HD (1920 × 1080).
- Если горячие клавиши не сработали, повторяйте нажатие, пока скрипт не отреагирует. :)
- Если установить нулевую паузу между покупками, остановить торговлю можно только полным завершением работы скрипта.
- Ботинки с зачарованием «Подводная ходьба» нарушают работу скрипта: он может начать бить жителя вместо торговли.
- Для корректной работы Minecraft должен быть запущен в полноэкранном режиме или хотя бы в окне, развёрнутом на весь экран.

#### Советы

- Если появляется меню паузы или возникают похожие сбои, немного подождите: работа скрипта может восстановиться сама.
- Если ожидание не помогло, перезапустите скрипт или самостоятельно закройте меню паузы после предполагаемой покупки.
